# NetPulse - Smart Network Monitoring System

NetPulse is a modern Smart Network Monitoring System dashboard designed to monitor, analyze, and optimize network infrastructure through a clean and futuristic user interface.

This project is being developed as part of the internship project at Usha Martin Limited. The main objective of the project is to create a smart monitoring platform capable of visualizing network status, analytics, alerts, and infrastructure monitoring in a user-friendly environment.


---

# Features

## Authentication Page
- Modern Login UI
- Email & Password Input Fields
- Remember Me Checkbox
- Forgot Password Link
- Custom NetPulse Logo
- Glassmorphism Cyber Theme

## Dashboard
- Sidebar Navigation
- Network Status Cards
- Cybersecurity Inspired UI
- Responsive Layout
- Dark Mode Dashboard
- Analytics & Monitoring Sections

## UI Design
- Neon Glow Effects
- Grid & Flexbox Layouts
- Modern SaaS Styling
- Gradient Backgrounds
- Interactive Hover Effects
