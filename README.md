# Smart Network Monitoring System

A modern web-based Smart Network Monitoring System designed to monitor network devices, visualize network activity, and provide alerts during network failures or downtime.

This project focuses on creating an interactive dashboard for monitoring network status in real time with a clean and responsive UI.

---
## Internship Project

This project was developed as part of the internship program at Usha Martin.  
The objective was to design and develop a smart solution for monitoring network systems, detecting failures, and improving network management efficiency through an interactive dashboard interface.

The project reflects concepts related to:
- Network monitoring
- Device tracking
- Alert systems
- Dashboard visualization
- Smart infrastructure management

---
## Features

- User Login Interface
- Interactive Monitoring Dashboard
- Network Device Monitoring UI
- Network Status Indicators
- Alert and Notification Sections
- Responsive and Modern Design
- Easy Navigation Between Pages

---

## Project Objective

The goal of this project is to simulate a smart network monitoring environment where users can:

- Track network activity
- Detect network failures
- Monitor connected devices
- Visualize network performance
- Improve network management efficiency

This project is inspired by real-world industrial and enterprise network monitoring systems.
